# Configurações de IA responsivas

A seção **Ordem automática** concentra a inclusão e a priorização dos provedores.

- O botão **Adicionar IA** fica no cabeçalho da própria seção.
- Os cards usam uma grade responsiva e quebram de linha conforme o espaço disponível.
- Não existe rolagem horizontal da lista de provedores.
- Em telas pequenas, cada card ocupa uma linha inteira.
- A ordem visual continua sendo a ordem usada pelo autopilot.
- Desktop usa arraste nativo com mouse.
- Dispositivos de toque podem reorganizar os cards pelo puxador do card.
- A nova sequência é salva automaticamente no backend.

O modal de cadastro e edição continua preservando as chaves existentes quando o campo de API key fica vazio.
